ℹ️ Wie funktioniert der CIDR Calculator?

  • 1. Gib deinen VPC CIDR Block ein (z.B. 10.0.0.0/16)
  • 2. Füge Subnets manuell hinzu oder nutze die "Vorschläge"-Funktion
  • 3. Berechne den VPC Plan und prüfe auf Overlaps
  • 4. AWS reserviert automatisch 5 IPs pro Subnet (Network, Router, DNS, Reserved, Broadcast)

🎯 Best Practices

VPC Design

  • • Nutze private IP-Ranges (10.x, 172.16.x, 192.168.x)
  • • Wähle /16 für Flexibilität (AWS Standard)
  • • Plane genug Platz für zukünftiges Wachstum
  • • Vermeide Overlaps mit anderen VPCs

Subnet Strategie

  • • Mindestens 3 AZs für High Availability
  • • Public Subnets für Load Balancer / NAT Gateway
  • • Private Subnets für Application Server
  • • Separate Database Subnets isolieren
